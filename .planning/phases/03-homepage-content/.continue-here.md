# Phase 3 — COMPLETE and verified live

Room cards ("The Rooms") were rebuilt against the REAL categories_boxes DOM,
deployed to theme id 15 (branch phase-3-homepage-content), and visually
confirmed on https://libertytavern.forum/categories.

## What the earlier sessions got wrong (now fixed)

The prior §6b/§6-ext CSS targeted selectors that DO NOT EXIST in this install:
`.category-box-stat`, `.category-description`, `.category-title-link`,
`.category-stat .value`, `.num-topics/.num-posts`. All were dead code — which
is why name + stats never rendered. And the wax-seal 48px circle was applied to
`.badge-category` itself, which crushed the category name (it lives INSIDE that
span, next to the icon) down to ~5px wide.

## Real DOM (verified via live DevTools, 2026-08-29)

```
.category-box > .category-box-inner
  .category-logo            (empty — hidden via CSS)
  .category-details
    .category-box-heading > a.parent-box-link > h3
      > span.badge-category__wrapper > span.badge-category[.restricted][--style-*]
          > [img.emoji | svg.d-icon-lock]?   (icon optional)
          > span.badge-category__name        (the category name)
    .description > div > span
    .subcategories > a.subcategory > a.badge-category__wrapper > ...  (optional)
```

Topic/post counts are NOT in this DOM. They come from the Category model
(`topic_count`, `post_count`) via the connector.

## The fix (commit d182929)

- **Badge**: circle is now a `::before` pseudo on the heading badge, so the name
  flows beside it. Emoji icons center on the circle; the restricted lock svg is a
  small corner overlay. Square (no-icon) categories show a plain colored seal.
- **Layout**: hide empty `.category-logo`, flex `.category-box-inner`, indent
  `.description` + `.subcategories` to align under the name.
- **Subcategories**: styled as chips with a category-color left edge.
- **Counts**: `tavern-room-preview.gjs` connector now renders
  `topic_count`/`post_count` (both always present) instead of the nonexistent
  `latestTopicTitle`; CSS pins the block top-right. Outlet
  `category-box-below-each-category` confirmed present (connectorsExist === true,
  1 connector mounted).
