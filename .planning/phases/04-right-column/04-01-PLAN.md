## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `/badges.json` -> DOM | Discourse returns badge JSON (public, unauthenticated). Field values (`name`, `icon`, `image_url`) are rendered into the rail template. |
| theme settings -> DOM | `settings.house_rules` (admin-editable) is split and rendered as list items. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Tampering (XSS) | badge `name` render | medium | mitigate | Render `{{b.name}}` as a plain interpolation so Glimmer auto-escapes; never wrap in `htmlSafe` (unlike the banner's `fancy_title`). |
| T-04-02 | Tampering (XSS) | badge `image_url` render | low | mitigate | Bind `image_url` only to an `<img src>` attribute; never inject as raw HTML. |
| T-04-03 | Information disclosure | `/badges.json` fetch | low | accept | Endpoint is public and unauthenticated; the rail exposes no data a logged-out user could not already see at `/badges`. |
| T-04-04 | Denial of service | badge fetch on mount | low | accept | Single cached GET on mount; `.catch(() => null)` degrades to a hidden panel. No retry loop, no polling. |
| T-04-05 | Tampering | `settings.house_rules` render | low | accept | Admin-only editable setting rendered via auto-escaped `{{rule}}` interpolation; admin is already trusted. |
